# StellaMatch Privacy Policy

## Data We Store
- Account details: name, email, hashed password.
- Profile details: city, bio, portfolio, GitHub username.
- Uploaded resumes (PDF files) and metadata.
- Skill tags, skill points, XP, Stella points, friends, and match activity.
- User activity logs for security and product analytics.

## How We Use Data
- Deliver authentication and matchmaking.
- Compute skill insights and game progression.
- Maintain transfer records for Stella points.
- Detect abuse and audit user actions.

## Your Choices
- Update profile and skill tags at any time.
- Request account deletion through administrators.

## Security
- Passwords are bcrypt-hashed.
- JWT is used for session authentication.
